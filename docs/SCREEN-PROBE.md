# Screen Probe 0.2 — 확대·필기 격리 실행

정지 확대, 라이브 확대(보기·필기 전용), 펜, 지우기, 되돌리기, 배율·이동을 복구했습니다. 이전의 전역 입력 훅·입력 주입·시스템 커서 숨김은 사용하지 않습니다.

**현재 검증 범위:** 합성 화면, 프로세스 장애 주입, 숨긴 창의 실제 메시지 처리와 메모리 GDI 출력. 실제 화면 캡처·GPU 라이브 확대·Zoom/Meet 수신은 이번 자동 검증에서 실행하지 않았습니다. 무정지 보장이나 수업용 검증 완료를 의미하지 않습니다.

## 실행

`dist/ScreenProbe/screen-probe.exe` 또는 `npm run dev`를 실행하면 일반 조작 창이 열립니다. 시작만으로 화면을 캡처하거나 확대 API를 초기화하지 않습니다. 원하는 기능을 직접 선택해야 확대가 시작됩니다.

```powershell
npm run dev
npm run dev -- --monitor 2
.\dist\ScreenProbe\screen-probe.exe --list-monitors
```

모니터 번호는 프로그램 목록 기준이며 Windows 설정 번호와 다를 수 있습니다. 초기 배율은 2배, 조절 범위는 1~4배입니다. `가상화면 연습` 버튼은 합성 체크무늬를 전체 화면에 표시하며 실제 화면을 캡처하지 않습니다. 이 버튼의 시각적 연습은 사용자가 직접 실행할 때만 시작합니다.

| 조작 | 동작 |
| --- | --- |
| Ctrl+1 / 정지 확대 버튼 | 선택 모니터를 한 번 캡처하여 확대. 활성 상태에서는 해제 |
| Ctrl+2 / 라이브 확대 버튼 | 선택 모니터의 움직이는 화면 확대. 활성 상태에서는 해제 |
| 휠, + / -, Ctrl+6 / 7 | 축소 / 확대 |
| 방향키 | 확대 영역 이동 |
| 마우스 왼쪽 버튼 | 필기 (펜은 처음부터 켜짐) |
| P / Ctrl+4 | 펜 켜기·끄기 |
| C / Ctrl+5 | 필기 전체 지우기 |
| Z | 마지막 선 되돌리기 |
| Esc / Ctrl+8 / 오른쪽 위 종료 버튼 | 확대 종료, 원래 앱으로 돌아가기 |
| Ctrl+9 / Alt+F4 | 프로그램 종료 |
| Ctrl+0 | 독립 감시 프로세스에서 작업 프로세스 전체 강제 종료 |

전역 키는 Ctrl+숫자만 등록합니다. Esc·문자·방향키·휠은 프로그램 창이 입력을 받을 때만 동작합니다. 필기 중 창 밖으로 나가거나 포커스를 잃으면 선을 종료합니다. 전체 화면 창은 항상 위 창이 아니며 Alt+Tab을 막지 않습니다.

확대 화면에서 원래 앱의 버튼을 클릭하거나 입력하는 변환 기능은 제공하지 않습니다. 펜을 꺼도 원래 앱으로 입력을 주입하지 않습니다. 원래 앱 조작은 Esc로 확대를 닫은 뒤 합니다. 라이브 필기는 화면의 원본 좌표를 기준으로 확대·이동에 따라 함께 움직입니다.

## 변경한 구조

- 독립 감시 프로세스가 먼저 비상키와 Windows Job을 준비합니다. 작업 프로세스는 Job에 등록된 뒤 시작 신호를 받아야 초기화할 수 있습니다.
- 초기화 8초, UI 응답 3초, 활성 세션 5분 제한을 감시 프로세스가 관리합니다. 제한 초과 시 확대·캡처 프로세스를 함께 종료합니다.
- 정지 캡처는 별도 프로세스에서 수행합니다. UI는 결과를 비동기로 받고, 4초 내 완료되지 않으면 캡처 프로세스를 폐기합니다.
- 감시 프로세스가 강제 종료돼도 Job의 종료 정책으로 작업 프로세스가 남지 않도록 했습니다.
- 커서 표시·위치 변경, 전역 입력 훅, 입력 주입, 마우스 캡처를 제거했습니다. 복원 API를 호출해야 커서가 돌아오는 구조를 없앴습니다.
- 실제 캡처 픽셀은 메모리/파이프로만 전달하며 파일에 저장하지 않습니다. 자동 검증의 이미지 파일은 합성 화면입니다.
- 프레임은 1,677만 픽셀 및 한 축 8,192픽셀 이하, 필기는 2,000개 선/100,000개 점으로 제한합니다.

이전 `native.rs`, `guardian.rs`, `diagnostics.rs`는 이력 참고용이며 빌드하지 않습니다.

## 화면에 영향을 주지 않는 검사

```powershell
npm test
npm run check
npm run test:isolated
npm run build
```

`test:isolated`와 `--smoke-test`는 실제 화면 캡처·Magnification 초기화·전역 단축키 등록·화면에 보이는 창·포커스 변경 없이 검사합니다. 숨긴 창과 메모리 비트맵, 합성 캡처 하위 프로세스를 사용합니다. `build`도 같은 검증과 PE import 검사를 통과한 뒤 배포본을 교체합니다. 빌드에는 Rust MSVC/SDK, import 검사에는 Python 3 표준 라이브러리가 필요합니다.
