## 본 제품 단계에서 검사할 항목

현재 프로토타입에 없는 형광펜, 지우개, undo/redo, 한글 텍스트 편집, 트레이, 설정 저장, 단축키 변경은 통과 처리하지 않습니다.

## 성능

프로토타입의 `Source refresh requests`는 API 호출 횟수이며 **렌더링 FPS가 아닙니다**. 최종 네이티브 렌더러에서 실제 프레임과 지연을 계측합니다.

| 지표 | 목표 | 측정값 |
| --- | --- | --- |
| FHD 라이브 렌더링 | 60fps | 미측정 |
| 4K 라이브 렌더링 | 최소 30fps | 미측정 |
| 로컬 입력→화면 반응 | 50ms 이내 | 미측정 |
| 대기 평균 CPU | 1% 이하 | 미측정 |
| 전체 프로세스 메모리 | WebView2 포함 보고 | 미측정 |

로컬 확대의 원본 픽셀 보존과 수신 영상의 회의 압축 품질을 따로 기록합니다.
