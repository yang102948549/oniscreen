2. 마우스 포인터 강조

아래 영역 위에서 마우스를 움직이고 클릭해 보세요. 좌클릭=블루 파문, 우클릭=앰버 파문, 누르고 있으면 링이 줄어든 채 유지됩니다.

강의 화면 (예시)
여기서 움직이고 클릭
요소스펙
포인터 + 후광실제 마우스 포인터는 항상 그대로 표시(숨기거나 대체하지 않음). 그 주변에 지름 44px(28~80 조절) 원이 포인터 끝점을 중심으로 함께 이동 · 노션블루 18% 채움 + 1.5px 링. 필기·확대 중에도 유지.
좌클릭 파문블루 링이 지름 24→72px로 확장, 불투명도 .8→0, 450ms ease-out.
우클릭 파문앰버(#EBA640)로 같은 애니메이션 → 좌/우 구분 가능.
누르는 중후광이 .75배로 수축 + 채움 진하게(35%), 뗄 때 파문 발생. 필기(드래그) 중에도 포인터는 유지하고 후광은 펜 색 링으로 바뀜.
접근성색에만 의존하지 않도록 링 두께·크기 변화도 함께 사용. 설정에서 "움직임 줄이기" 시 파문 대신 링 깜빡임 1회.
구현 주의오버레이 창이 클릭을 가로채면 안 됨 → 창을 click-through(WS_EX_TRANSPARENT)로 두고, 마우스 위치/클릭은 전역 후크(WH_MOUSE_LL)로 받아 후광·파문만 그림. 시스템 커서는 건드리지 않으므로 포인터가 사라질 일이 없음. 화면 확대 중에는 캡처 이미지에 커서가 안 찍히므로, 확대 화면 위에 실제 커서 모양(GetCursorInfo)을 직접 그려 줌. 필기 모드일 때만 입력을 오버레이가 받음.

3. 디자인 원칙

영역결정
톤화이톤 = Oni bg/canvas #FAFAF9 · surface #FFF · subtle #F3F3F1. 순백/순흑 대신 웜 그레이 텍스트 #292927. 툴바는 흰 surface + 1px #DCDCD6 테두리 + 옅은 그림자.
노션 블루활성 상태 = soft #EAF3FD 배경 + #1B70C9 아이콘, 포커스 링/선택 링 = #2383E2. 블루는 "지금 켜진 것" 한 곳에만 사용 → 눈에 띄는 포인트 유지.
컴팩트컨트롤 36px(Oni 기본) / 보조 28px · 간격 4/8 · 아이콘 18px 선형(1.7px) · 라벨 없이 아이콘만, 툴팁으로 설명.
브랜드Oni Class 블루(#007AFF 계열) 앱 아이콘 22px을 툴바 좌측 드래그 핸들로. 상태색(성공/경고/오류)은 브랜드색과 분리.
필기 색검정 · 블루 · 레드 · 틸 · 앰버 5색 (Oni status 토큰 재사용). 칠판/PPT 위 가독성 위해 펜은 진한 색, 형광펜은 accent 색 35% 투명도.
타이포Noto Sans KR (Figma 기준) → 앱에서는 Pretendard 대응 검토. 본문 14/22, 캡션 12/18.
모션120ms ease-out 이하. 접기/펼치기, 툴팁만. 필기 지연을 만드는 애니메이션 금지.

5. 기술 스택 제안

  • 현재 코드(crates/screen-probe)는 좌표 엔진(Viewport/Zoom, 음수 좌표 모니터 대응)만 있고 UI가 없음 → 엔진은 유지.
  • UI는 Tauri 2(투명 always-on-top 오버레이 창 + 웹 UI)로 위 시안을 그대로 구현. 필기는 Canvas 2D, 확대는 Rust 쪽 화면 캡처(Windows Graphics Capture)를 오버레이에 표시.
