# 확대·필기 복구 검증 — 2026-10-13

## 구현

0.2.0에서 정지 확대, 라이브 보기/필기, 펜 토글, 전체 지우기, 마지막 선 되돌리기, 휠/키 배율 조절, 방향키 이동을 연결했습니다. 이전 입력 변환과 커서 숨김은 복구하지 않았습니다. 이는 기능을 모두 막는 차단판이 아니라 별도 프로세스에서 동작하는 새 엔진입니다.

## 검증 원칙

사용자의 실제 화면을 캡처하거나 전체 화면으로 덮지 않았습니다. 실제 Magnification 초기화, 입력 훅, 커서 조작, 전역 단축키, 실제 키/마우스 입력 주입을 실행하지 않았습니다. 보이는 UI 대신 숨긴 창 및 GDI 메모리 비트맵을 사용했습니다. 가상화면 연습 버튼도 자동으로 누르지 않았습니다.

## 검사 항목

- 좌표/휠 및 순수 엔진 단위 테스트: 확대 픽셀 매핑, 확대·이동 뒤 필기 좌표 보존, 창 밖에서 선 종료, 되돌리기, 저장량 제한, 파이프 데이터의 크기·절단·추가 바이트 검증.
- 캡처 하위 프로세스: 정상 합성 데이터, 잘린 데이터 거부, 응답 정지 시 제한 시간 후 종료.
- 독립 감시: 정상 종료, 초기화 전 정지, READY 이후 응답 정지, 비정상 종료 코드, 응답 중에도 활성 세션 제한, 감시 프로세스 급작스러운 종료 시 자식 정리.
- 숨긴 실제 창: 확대·필기·되돌리기·Esc 메시지 처리, 정지 이미지와 투명 라이브 필기층의 실제 메모리 GDI 출력, 테스트 모드의 실제 캡처/라이브 API 진입 거부.
- 실행 파일 import 검사: 입력 훅/SendInput/BlockInput/커서 표시·위치 변경/마우스 캡처/시스템 전체 확대 API 없음. Job 관리 API 포함. 동일 DLL의 복수 import descriptor도 합쳐 검사.
- 합성 체크무늬와 필기 이미지 `restored-fixture.png`를 생성하고 시각 확인.

## 남은 실제 환경 검증

실제 캡처 픽셀, Magnification의 GPU 출력, 물리 마우스·다중 DPI·절전/모니터 분리, Zoom/Meet 수신 영상은 이번 자동 검사 범위 밖입니다. 모든 하드웨어에서 정지하지 않는다고 보장하지 않습니다. 시스템 커서 변경 경로를 없앴으며 앱 정지 시 독립 종료가 동작하는 것을 확인하는 방식으로 사고 경로를 줄였습니다.

## 최종 결과

- 단위 테스트 10개 통과.
- Clippy `-D warnings` 및 rustfmt 검사 통과.
- 격리 실행 검사: 캡처 3개, 독립 감시 6개, 숨긴 실제 UI/GDI 1개 시나리오 통과.
- 실제 최종 실행 파일의 PE import 검사 통과. 입력 가로채기·커서 변경 API 없음, Job API 포함.
- Windows 10/11 manifest가 포함된 빌드에서 투명 자식 창 생성/메모리 출력 확인.
- 작업 프로세스가 멈춘 상황뿐 아니라 감시 프로세스가 Rust Drop을 실행하지 않고 종료한 상황에서도 자식 프로세스가 종료됨을 프로세스 핸들로 확인.
- 검증 시 보이는 창·실제 화면 캡처·Magnification 호출·전역 단축키·포커스 변경 없음.
- `scripts/build-probe.ps1`은 이제 import 검사와 격리 검증이 실패하면 배포본을 교체하지 않음.
